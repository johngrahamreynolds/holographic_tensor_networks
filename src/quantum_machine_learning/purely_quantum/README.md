# Purely Quantum Machine Learning

## Overview

This directory contains implementations of purely quantum machine learning algorithms that operate entirely within the quantum domain, without requiring classical optimization loops.

## Examples

- **Quantum Kernel Methods**: Quantum feature maps and kernel-based learning
- **Quantum Support Vector Machines**: Fully quantum implementations of SVM
- **Other end-to-end quantum learning algorithms**

## Note

This is a niche and rapidly evolving area. Many "purely quantum" algorithms still require some classical processing for data encoding or measurement interpretation, so the distinction from hybrid approaches can be fluid.

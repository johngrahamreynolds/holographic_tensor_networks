# Hybrid Quantum-Classical Machine Learning

## Overview

This directory contains implementations of hybrid quantum-classical machine learning algorithms. These algorithms combine quantum circuits (typically parameterized) with classical optimization routines to solve learning and optimization tasks.

## Examples

- **Quantum Convolutional Neural Networks (QCNNs)**: Quantum analogues of classical CNNs that use quantum convolution and pooling layers
- **Variational Quantum Eigensolvers (VQE)**: Hybrid algorithms for finding ground states of quantum Hamiltonians
- **Quantum Approximate Optimization Algorithm (QAOA)**: Hybrid approach for combinatorial optimization problems
- **Quantum Neural Networks (QNNs)**: Parameterized quantum circuits trained via classical optimization

## Tensor Network Perspective

From a tensor network viewpoint, these algorithms involve:
- Parameterized quantum circuits as structured tensor networks
- Classical optimization over tensor network parameters
- Connections to variational tensor network methods in many-body physics
